# Azure AI Foundry Wiki

A persistent, source-grounded knowledge base about Azure AI Foundry, organized to support learning from platform fundamentals toward enterprise deployment.

The wiki starts with a clean OKF v0.2 framework. Add source material under [sources/](sources/README.md), then ask Codex to ingest it into the linked knowledge bundle at [wiki/](wiki/index.md). The roadmap document supplied during setup has not yet been copied or ingested; add it to the inbox when ready.

## Start here

1. Add curated source material under [sources/](sources/README.md).
2. Ask Codex to ingest the new material into the wiki.
3. Browse concepts and Maps of Content from [wiki/index.md](wiki/index.md).
4. Use [scripts/wiki_tool.py](scripts/wiki_tool.py) for structural checks, source integrity, catalog builds, and search.

[AGENTS.md](AGENTS.md) defines source handling, provenance, concept linking, and the ingest, query, and lint workflows. [scripts/README.md](scripts/README.md) explains the deterministic maintenance tool.
