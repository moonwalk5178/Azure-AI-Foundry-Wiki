🛡️ Azure AI Evaluation & Quality Framework

Quantifying LLM outputs using the azure-ai-evaluation SDK metrics (Scale 1 to 5).

Groundedness (1-5)

Measures if response claims are strictly derived from retrieved context sources. Essential for eliminating hallucinations.

Relevance (1-5)

Assesses whether response directly and efficiently answers the prompt without adding tangential fluff.

Tool Call Accuracy (1-5)

Evaluates how accurately an agent invokes external MCP or function parameters based on user instructions.

🏗️ Capstone Blueprint: Intelligent Enterprise Retail Agent (IERA)

The ultimate test of your Azure AI Foundry skills is constructing the IERA capstone system.
